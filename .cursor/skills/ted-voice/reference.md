## Expanded ban list

Hard no (and close cousins):

| Avoid | Why |
|-------|-----|
| delve into / dig deep into | Empty opener |
| unlock potential / unlock the power of | Hype |
| in today's world / in today's digital landscape | Filler |
| instrumental / significant / cutting-edge | Inflated filler |
| leverage / utilize (when "use" works) | Corporate |
| synergy / align stakeholders / circle back | Meeting-speak |
| game-changer / revolutionary | Inflated |
| I'm excited to announce / thrilled to share | Press-release |
| nestled / tapestry / landscape of / journey | AI purple prose |
| robust / seamless / holistic (as empty modifiers) | Soft buzzwords |
| elevate / empower / supercharge / unleash | LinkedIn |
| foster / cultivate / harness / embark | Soft buzzwords |
| nuanced / multifaceted / intricate | Vague sophistication |
| crucial / pivotal / vital / essential (as filler) | Intensifier padding |
| it goes without saying / needless to say | Throat-clearing |
| furthermore / moreover / thus / additionally (when a period works) | Stiff essay voice |
| "As a …" throat-clear that restates the obvious | Performative |

If something sounds like it was written by committee for LinkedIn, cut it even if it is not on this list.

## AI slop checklist

### Sentence structures

| Pattern | Example |
|---------|---------|
| False contrast | "It's not X, it's Y" / "This isn't about X. It's about Y." |
| "X for Y" framing | "Think of it as Notion for designers" |
| Punchy stoppers | "This changes everything." "That's the point." "And that matters." |
| Rhetorical Q + own answer | "The result? Faster shipping." |
| Throat-clear openers | "Here's the thing:" / "Here's why:" / "The kicker?" |
| Forced rule of three | Exactly three adjectives or three parallel clauses every time |
| Colon reveals | "One word: clarity." |
| "Whether you're…" openers | "Whether you're a designer or a founder…" |
| One-line moral at paragraph end | Restating what was just said as a tidy takeaway |

### Punctuation and formatting

- Em dashes, especially several per paragraph
- Bolded lead-ins on every bullet (`**Speed:** …`)
- Headers and bullets on content that should be a few sentences of prose
- Emojis as bullet markers or section openers
- Title Case On Every Heading

### Openers and closers

- "Great question!" / "Absolutely!" / "Certainly!"
- Restating the question before answering
- "In conclusion," "Ultimately," "At the end of the day"
- Closing with an offer nobody asked for ("Let me know if you'd like…")
- Inspirational sign-offs: "The future is bright." "The possibilities are endless."

### Tone and hedging

- Over-hedging: "It's worth noting that," "It's important to remember"
- Both-sidesing everything instead of taking a position
- Generic praise with no specifics ("This is a powerful approach")
- Uniform enthusiasm: every point framed as equally exciting
- Vague claims with no concrete example, number, or name

### Rhythm

- Every paragraph the same length
- Every sentence medium length; no variation between short and long
- Perfectly parallel structure across all list items
- Transitional filler: "Moreover," "Furthermore," "Additionally"

## Mechanics cheat sheet

| Rule | Do | Don't |
|------|----|-------|
| Dashes | Comma, period, paren, colon, or "to" | Em dash (`—`), en dash (`–`) |
| Lists | Oxford comma ("design, research, and code") | Skip the last comma |
| Titles | Sentence case ("How I review design work") | Title Case Everywhere |
| Length | Short paragraphs; cut throat-clearing; match or shorten existing | Expand without a reason; long wind-ups before the point |
| Humor | Dry, understated, earned | Forced jokes or emoji humor |
| Examples | Concrete name, number, or story | Abstraction that could fit any topic |

## Surfaces cheat sheet

| Surface | Notes |
|---------|--------|
| Blog / newsletter | Full voice; headings, lists, quotes, images welcome |
| Case studies | Factual, outcome-aware; still human, not press kit |
| Bio / How I Think | First person; clear and heartfelt; no résumé buzzwords |
| Homepage / UI | Shorter; same plain words; no marketing funnel tone |
| Captions / alt | Descriptive and specific; not cute for its own sake |
| Social (X / Bluesky / LinkedIn) | 2 variants per platform; char counts for X and Bluesky; no hashtags |
| Slack | Point first; short; `*bold*` + bullets; one version unless asked |
