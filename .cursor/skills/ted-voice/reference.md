## Expanded ban list

Hard no (and close cousins):

| Avoid | Why |
|-------|-----|
| delve into / dig deep into | Empty opener |
| unlock potential / unlock the power of | Hype |
| in today’s world / in today’s digital landscape | Filler |
| leverage / utilize (when “use” works) | Corporate |
| synergy / align stakeholders / circle back | Meeting-speak |
| game-changer / revolutionary / cutting-edge | Inflated |
| I’m excited to announce / thrilled to share | Press-release |
| nestled / tapestry / landscape of / journey | AI purple prose |
| robust / seamless / holistic (as empty modifiers) | Soft buzzwords |
| elevate / empower / supercharge | LinkedIn |
| it goes without saying / needless to say | Throat-clearing |
| furthermore / moreover / thus (when a period works) | Stiff essay voice |
| “As a …” throat-clear that restates the obvious | Performative |

If something sounds like it was written by committee for LinkedIn, cut it even if it is not on this list.

## Mechanics cheat sheet

| Rule | Do | Don’t |
|------|----|-------|
| Dashes | Comma, period, paren, colon, or “to” | Em dash (`—`), en dash (`–`) |
| Lists | Oxford comma (“design, research, and code”) | Skip the last comma |
| Titles | Sentence case (“How I review design work”) | Title Case Everywhere |
| Length | Short paragraphs; cut throat-clearing | Long wind-ups before the point |
| Humor | Dry, understated, earned | Forced jokes or emoji humor |

## Surfaces cheat sheet

| Surface | Notes |
|---------|--------|
| Blog / newsletter | Full voice; headings, lists, quotes, images welcome |
| Case studies | Factual, outcome-aware; still human, not press kit |
| Bio / How I Think | First person; clear and heartfelt; no résumé buzzwords |
| Homepage / UI | Shorter; same plain words; no marketing funnel tone |
| Captions / alt | Descriptive and specific; not cute for its own sake |
