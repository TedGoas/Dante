I created **Cerberus**, an open source HTML email framework, because everywhere I worked eventually needed to build HTML emails, and nobody wanted to do it. If you’ve ever had to code an email and hated it, I don’t blame you. It can be rough. Eventually I raised my hand and said sure, I’ll give it a shot. That’s when the learning began.

Over time I built up a library of patterns for marketing emails, transactional emails, even data visualization. Designs that worked in Gmail and Outlook, which are notoriously hostile toward HTML and CSS. I open sourced some of that code to learn GitHub. A few major publications picked it up, the repo took off, and I got a lot of experience working with the open source community as the sole owner.

At Stack Overflow I turned Cerberus into one of the first email design systems ever. It ended up in millions of emails a year. Development eventually slowed into maintenance mode, and when the chance to sell came along in 2025, it felt like Cerberus had run its course in my hands.
